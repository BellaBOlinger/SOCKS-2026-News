# SOCKS-2026-News

This repository contains the code used for my research project conducted over the 2026 Summer through the VT EPSCoR SOCKS Internship in collaboration with UVM’s Center for Community News (CCN). The available datasets are also provided, however some belong to the CCN and cannot be shared by me. A description of the paper written as the deliverable for this research is attached below and the paper is in the repository.

**Title:** ***Can College Newspapers Save the Day?** A topic model analysis of critical information and community cohesion.* 

**By:** Bella Olinger

**Abstract:** A limited news area (LNA) is a community with limited or no access to local news (Metzger 2025). This is detrimental since local news provides critical information as well as creates community cohesion (Khanom et al. 2023; Napoli et al. 2018; Waldman 2023). To combat this loss of local news, some colleges have started covering the local communities as opposed to just campus news (Bhowmik et. al. 2026). This research aims to discover what college papers discuss when covering the local community, specifically if it is critical information or community cohesion. We will also be looking at how a college’s proximity to LNAs and news partnership status affects the topics of news articles. We will apply Latent Dirichlet Allocation (LDA) topic modeling to learn what college papers are discussing. We expect colleges to discuss community cohesion more than CIN. We also expect that colleges in or adjacent to LNAs are more likely to cover critical information needs (CIN) than those not in LNAs. Because of the difference in mission between news partnerships and regular student media, we expect that news partnerships will discuss CIN more regardless of their proximity to a LNA. College journalists cannot replace professions, so knowing what they are discussing and why can help provide quality news to millions of Americans.

### The Code Notebooks

**Data Cleaning.ipynb** contains all the code and information regarding the cleaning of the original dataset. This includes changing publication names, combining datasets, dropping articles, and creating new variables. The original publication and story datasets from the CCN’s Hugging Face (https://huggingface.co/center-for-community-news) were used, which are currently private. We also used the final_pub.csv dataset. This was created exclusively for this project and contains the name of each publication, their institution, news partnership status, and their story count as well as additional notes. Final_pub.csv can be found in the data folder in this repository. This code produces two dataframes, full_pub_df and full_story_df, which are the main data used in the analysis.

The **EDA and TM.ipynb** contains exploratory data analysis (EDA) and the actual creation of the LDA topic model. The EDA looks at the distribution and count for different variables for both publications and stories/articles. To tune the LDA model on our code we needed to use the Vermont Advanced Computing Center (VACC) because of the size of our data. The code run through the VACC is in the notebook and the coherence values are in Appendix B. We also created aggregated topics for CIN/community cohesion, our metatopics, and the International Press Telecommunication Council media codes. More about this can be found in the paper.

The visualization and statistical analysis used in the result section of the paper can be found in **Viz and Stats.ipynb**. This notebook contains the unedited visualizations, as well as some additional ones and average proportions. The reasons for choosing each statistical test, their assumptions, hypotheses, and p-value can also be found in this notebook. All of the data used was created in EDA and TM.ipynb after aggregating the topics and can be found in the data folder of this repository, except the ungrouped CIN/community cohesion one because it was too large.
